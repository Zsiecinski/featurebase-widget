Loop roadmap

What's shipped, what's in progress, what's coming next, and what we're still exploring. Updated as we ship.

Shipped v1.0 — Launch

Available today in the Intercom App Store. Free during early access.

  • NEW
    Recently shipped card on Messenger Home
    Live Featurebase changelog rendering inside Intercom's Messenger. NEW / IMPROVED / FIXED color-coded pills, ship dates, comment counts.
  • NEW
    Detail view with full release notes
    Tap any item to read the complete release note inline. "Open on Featurebase" button for customers who want to comment or upvote.
  • NEW
    Optional "Coming next" section
    Surface in-progress roadmap items with upvote counts. Loop becomes a forward-looking habit, not just a retrospective view.
  • NEW
    Per-workspace configuration
    Featurebase API key, category filter, display toggles, custom header text, custom footer button. No code required.
  • NEW
    Encrypted at rest, HMAC-verified webhooks
    Featurebase API keys are encrypted with AES-256-GCM. All Canvas Kit webhook requests are verified via HMAC-SHA256 signature before processing.

In progress Quietly building

Likely to land in the next 30-60 days. Free workspaces will see most of these.

  • IMPROVED
    Loop Analytics dashboard
    See exactly how Loop is performing for your workspace: card renders, item clicks, click-through rate, top-clicked items, "deflection rate" estimate. This is the headline Pro feature — admins want proof Loop is working.
    Backend already tracking events. Dashboard UI in design.
  • IMPROVED
    Multi-category support
    Currently you can filter to one Featurebase category. Multi-product orgs want to show 2+ categories or all-of-the-above.
  • IMPROVED
    Better empty + error states
    If your Featurebase has no recent changelog entries, Loop should say so gracefully. If the API key revokes, customers should see a clean "this card is being updated" message — not a broken canvas.

Planned Pro tier candidates

Features being designed for the future Pro tier ($19-29/mo per workspace). Existing Free users will be grandfathered.

  • PLANNED
    Custom branding (your colors, your logo)
    Replace Loop's coral with your brand's colors. Add your logo to the card header. For agencies and customers who want white-label.
  • PLANNED
    Segment targeting
    Show different Loop content to different Intercom segments. Pro plan users see "Coming next" items relevant to their tier; trial users see "what shipped that you might love."
  • PLANNED
    Multi-source integrations
    Loop becomes the customer-facing roadmap layer across PM tools — Linear, Productboard, Notion, Trello. Pull from any source, render with Loop's familiar Intercom-native UI.

Exploring Wild ideas

Ideas we're thinking about but haven't committed to. Feedback shapes which of these get built.

  • EXPLORING
    Conversation triggers
    Pattern-match Messenger conversation text to changelog/roadmap items. When customer asks "is X fixed?", auto-surface the relevant FB item inline before your support team responds. The "wow" feature.
  • EXPLORING
    Search within Loop
    Inline search across your changelog from inside the Messenger. Customers can type to filter without opening a new tab.
  • EXPLORING
    Localization (i18n)
    Featurebase supports multiple locales per entry. Loop should detect the customer's Intercom locale and render in their language.
  • EXPLORING
    Public uptime dashboard
    For enterprise customers who need to see Loop's reliability before installing. Daily uptime numbers, incident history.
