What Loop does

Recently shipped. Coming next. Inside chat.

Loop sits on your Messenger Home screen and pulls live from your Featurebase API. Publish in Featurebase → it appears in Loop within seconds.

Color-coded type badges

Every shipped entry gets a colored pill: green NEW, purple IMPROVED, orange FIXED. Customers parse the page at a glance.

Coming next preview

Optional section below the shipped list showing in-progress roadmap items. Builds anticipation, turns Loop into a habit.

Drill-down detail view

Tap an item to expand the full update — title, hero image, body content with proper section headers — without leaving Messenger.

Configurable per workspace

Toggle every section on or off. Customize header text, button labels, item counts. No code, no deployment.

Live sync, no caching

Publish a Featurebase changelog → it's in Loop within seconds. Hide an entry → Loop hides it instantly. Always in sync.

Respects your privacy flags

If you've hidden an entry from your Featurebase board, Loop hides it too. Your public face stays consistent across surfaces.

How it works

From install to live in 2 minutes.

1

Install from the Intercom App Store

One click. Loop appears in your Developer Hub and is ready to add to Messenger Home.

2

Paste your Featurebase API key

Get it from Featurebase Settings → API. Paste once into Loop's Configure screen. Done.

3

Add Loop to Messenger Home

Drop it on your Home screen, set audience rules if you want, save. Customers see it on their next visit.

FAQ

Common questions.

What do I need to use Loop?
A Featurebase organization with the changelog feature enabled, an Intercom workspace on a plan that supports Messenger apps, and about 2 minutes to install and configure.
Where does Loop store my data?
Your Featurebase API key is encrypted at rest with AES-256-GCM and stored in our Postgres database. We don't store any of your customers' Intercom Messenger data — Loop only reads what's required to render each Canvas Kit response. See our privacy policy for details.
Can I filter Loop to one product line?
Yes. In Loop's Configure screen, set the Category filter to match a Featurebase category name (or substring). Multi-product workspaces can install Loop multiple times with different category filters on different Messenger surfaces.
Does Loop work with the Messenger on my mobile apps?
Loop uses Intercom's Canvas Kit, which renders natively wherever Intercom does — web, iOS Messenger SDK, Android Messenger SDK. The styling adapts to each surface automatically.
Is Loop affiliated with Featurebase or Intercom?
No. Loop is an independent third-party app. It uses Featurebase's public API and Intercom's Canvas Kit, but isn't built or endorsed by either company.
How do I get help?
Email support@loop-app.example with your Intercom workspace ID and a description of the issue. We respond within 1 business day.
